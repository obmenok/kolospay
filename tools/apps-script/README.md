# Запись выписки в Google-таблицу

1. Откройте таблицу «Колос_финансы» → Расширения → Apps Script.
2. Вставьте содержимое `Code.gs` (заменив всё), в функции `setCode` впишите свой секретный код.
3. Выберите функцию `setCode` → «Выполнить» → разрешите доступ. Потом замените код в тексте на `ЗАМЕНИТЕ-НА-СВОЙ-КОД` (чтобы код не хранился в скрипте).
4. Развернуть → Новое развёртывание → Тип: Веб-приложение; Выполнять от имени: Я; Доступ: Все. Скопируйте URL.
5. Вставьте URL в `static/js/treasurer-config.js`, закоммитьте.
6. На странице казначея введите код один раз (запоминается в браузере).
